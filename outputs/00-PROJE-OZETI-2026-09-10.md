## 1. Sistem tek bakışta

Hezarfen bir **okul yönetim + öğrenme platformu**. `Hezarfen-Co` org'unda **4 depo**:

| Depo | Yığın | Rolü | Yerel HEAD |
|---|---|---|---|
| `hezarfen_backend` | Rust 2024 · axum · SurrealDB 3 · tokio | REST API + oturum-çerezli auth + 5 hiyerarşik rol + **QUIC AI köprüsü (`hab/1`)** | `06fee28` |
| `hezarfen_frontend` | SolidJS + TS · Vite · TanStack Router · Tailwind · Bun | Web arayüzü + **Çelebi** paneli | `8087fda` (PR #59 merge) |
| `hezarfen_rule_based_chatbot` | Python (stdlib) + aioquic | **Çelebi** — kural-tabanlı kullanım asistanı | `559d04d` |
| `hezarfen_rag` | Python · PyMuPDF · BGE-M3 · Qdrant · FastAPI | **RAG servisi**: kaynakla konuşma + kanıtlı özet + benzer-soru | `1201eb7` |

**Bağlantı deseni** `[DOĞRULANDI]`: AI servisleri backend'e HTTP'den değil **QUIC
köprüden** bağlanır. Çelebi `chat.reply` yeteneğini register eder
(`hezarfen_rule_based_chatbot/src/bridge.py`, protokol `hab/1`, rol
`asker_role` alanından **sunucu-tarafı** gelir). Veri çeken servis **api-read**
kanalını kullanır (backend axum router'ına iç-dispatch, read-only, rol-gated).

**RAG'in bağlanma şekli** `[DOĞRULANDI, karar D3]`: RAG **QUIC değil, ayrı HTTP
servisi** olarak karar verildi — `hezarfen_rag/src/service/http_app.py` (FastAPI).
Backend bu HTTP'yi çağırır; sözleşme `hezarfen_rag/docs/API-CONTRACT.md`.
(Obsidian `rag/README.md` hâlâ "QUIC api-read (öneri)" diyor → `[BAYAT]`.)

### Domain (backend README'den) `[DOĞRULANDI]`
Roller: `parent < student < teacher < manager < admin`. Notlar kullanıcıya özel +
**dosya ekli** (PDF); mesajlaşma; yoklama (etkinlik + katılımcı + audience);
kurs-şekilli notlandırma (course / study-etüt / club-kulüp, subjects, sınavlar);
şube (*şube* 9-A/10-B); kayıt listeleri.

**RAG'in korpusu buradan gelir** `[DOĞRULANDI, karar D1]`: **course-notes** —

Frontend: `src/api/course-notes/*`. RAG bunu **yeniden inşa etmez, tüketir**.

## 2. Çelebi (kural-tabanlı chatbot) — BİTTİ

`[DOĞRULANDI]` Harici çalışma-zamanı bağımlılığı yok (stdlib), offline çalışır;
tek istisna QUIC köprüsü (`aioquic`).

- **Bilgi kaynağı:** `docs/hezarfen-site-rehberi.md` (gerçek sayfa/rol/akış tanımı)
- **Boru hattı:** `engine.handle_request` → `normalize` (TR) → `rules` (yüksek
  kesinlik anahtar kelime) → `similarity` (TF-IDF karakter n-gram + kosinüs) →
  `domain` (kapsam-dışı/OOS kapısı) → `decision` (eşik + **rol gating**) →
  `responder` (varyant + selam aynalama) + `observability`
- **Katalog:** 98 intent + cevap metni + route + rol modeli
- **Değerlendirme:** `data/benchmark.jsonl` = **tek gold kaynak, 601 soru** (98
  intent + OOS, rol dahil) → `benchmark_qa_report.py --strict`; ayrıca
  `stress_benchmark.py` ile **10.000** stres girdisi (9.000 uygulama-içi + 1.000 OOS)
- **Frontend tarafı** `[DOĞRULANDI]`: Çelebi cevabı artık **yazarak akıyor**
  (karakter-sayımı reveal, skip kontrolü, `prefers-reduced-motion`'da animasyon
  yok), transkript en yeni mesajı takip ediyor, `chat.reply`'ın **eylem** yarısı
  render ediliyor (açılacak sayfa butonu + emin olmadığında takip-soru çipleri),
  `safeCelebiRoute` yalnız uygulama-içi yola izin veriyor (frontend commit `6f30785`,
  issue #55-#57).

## 3. hezarfen_rag — asıl odak

### 3.1 Ne yapıyor (mimari, KESİN KARAR)
`[DOĞRULANDI]` Obsidian `rag/mimari.md §0.1` (Kadir onaylı, 2026-09-02):
**Uyarlamalı + Hibrit + Hiyerarşik RAG.** Saf agentic DEĞİL, saf graph DEĞİL.

```
PDF → parse (PyMuPDF, blok+bbox+okuma sırası) → izolasyon (soru/cevap-anahtarı/
ön-arka madde retrieval'dan ÇIKAR) → TR normalize → görsel/tablo analizi →
CanonicalDoc (versiyonlu stabil span-id: <doc_id>#<sayfa>.<blok>)
  → chunk (çocuk 150-300 tok + üst 700-1500, parent-child)
  → embed BGE-M3 (dense+sparse, 1024d) → index Qdrant(gömülü) + rank_bm25(köksüz TR)
  → hibrit retrieval (dense40 + BM25-40 + sparse30) → RRF(k=60) + KASA İZOLASYONU
  → rerank BGE-reranker-v2-m3 (cross-encoder) + çeşitlilik + parent genişletme
  → FAIL-CLOSED kapısı (kanıt yoksa LLM HİÇ çağrılmaz)
  → generate DeepSeek: kaynak-sınırlı + [N] atıf + çekimser
  → guard (regex + LLM-sınıflandırıcı) + output_guard
```
Yan modüller: `summarize` (extract-then-abstract + RAPTOR-benzeri kanıtlı özet),
`memory` (history-aware rewrite), `context` (lost-in-middle + token bütçesi),
`cache` (Response + Embedding + corpus_version), `eval` (DeepEval + LLM-hakem),
`understand` (intent + NER), `observability` (RequestTrace), `question_gen`,
`ingest/ocr` (Tesseract-tur, opsiyonel), `ingest/visual_caption` (VLM captioning),
`pricing` + `costlog` (canlı token/$ ölçümü).

**Değişmez kurallar:** metadata filtresi zorunlu (`sınıf→ders→ünite→kazanım`) ·
cevap sızıntısı yasak · atıf zorunlu (sayfa/bbox) · kapalı kaynak (web yok) ·
kanıt yoksa "bu kaynaklarda yeterli kanıt yok".
